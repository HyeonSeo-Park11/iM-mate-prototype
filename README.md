# iM MATE 프로토타입

지오펜스 기반 소비 패턴 예측 → 카카오톡 대화방 모드 혜택 제안 → 생체 인증 원터치 가입까지
이어지는 흐름을 보여주는 **MVP 목업 앱**입니다. React Native(Expo) 기반이며, 실제 백엔드
연동 없이 모든 데이터는 `src/data/mock.ts`의 목 데이터와 타이머로 시뮬레이션합니다.

## 시나리오 흐름

1. **홈 화면** — 계좌/지역화폐/지원금 잔액 확인, "가맹점 근처 도착" 수동 시뮬레이션 버튼
2. **패턴 분석 시뮬레이션** — 소비 패턴 추론, 공공데이터, 마이데이터 연동을 흉내 낸 파이프라인 애니메이션
3. **위젯 노출** — 예측 소비 패턴 기반 잠금화면 스타일 위젯 카드
4. **카카오톡 대화방 모드** — 인앱 챗봇이 혜택(1:1 매칭 그랜트 예적금)을 대화형으로 제안
5. **사전 기입 신청서** — 마이데이터 기반 자동 입력된 신청 정보 확인
6. **생체 인증** — 지문 인증 시뮬레이션으로 최종 서명
7. **가입 완료** — 매칭 그랜트 이체 및 계좌 잔액 반영 결과 확인

## 실행 방법

```bash
npm install
npm run web      # 브라우저 미리보기 (가장 빠른 확인 방법)
npm run android  # 안드로이드 기기/에뮬레이터
```
